# .github

Default **community health files** for all [@neuron7xLab](https://github.com/neuron7xLab)
repositories. GitHub automatically falls back to the files in this repository for any
repo that does not define its own `CONTRIBUTING`, `CODE_OF_CONDUCT`, `SECURITY`,
issue templates, pull-request template, or funding configuration.

| File | Purpose |
|------|---------|
| [`CONTRIBUTING.md`](.github/CONTRIBUTING.md) | How to propose changes, the quality bar, the review loop |
| [`CODE_OF_CONDUCT.md`](.github/CODE_OF_CONDUCT.md) | Contributor Covenant v2.1 |
| [`SECURITY.md`](.github/SECURITY.md) | Coordinated vulnerability disclosure |
| [`SUPPORT.md`](.github/SUPPORT.md) | Where to ask questions |
| [`PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | PR checklist |
| [`ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Structured bug / feature forms |
| [`FUNDING.yml`](.github/FUNDING.yml) | Sponsor links |

> Editing a file here updates the default for **every** repository at once.
> A repository that ships its own copy of a file overrides this default.
